## pixel-kitty

The kittens, two dancing pixel kittens, replaces the orange working dots in the desktop app. The kittens plays 1 moves in a new order every turn.

## Choosing a pet

With several pet mods loaded, each turn shows one of them. Type `/pet kitty` or `/pet random` in the desktop app to choose for the rest of the session.
